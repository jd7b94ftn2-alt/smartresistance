# SmartResistance 固件

ESP32-S3-WROOM-1-N16R8 + 2.8 寸 ILI9341 / XPT2046 触摸屏 + EC11 旋钮。PlatformIO / Arduino 框架。
换回 N8R2 模块时，把 platformio.ini 里的 16MB、default_16MB.csv、qio_opi、BOARD_HAS_PSRAM 改回 8MB 配置。

> 状态：上一版（旋钮操作、英文界面）已在板子上烧录运行。这一版加入了中文、九宫格主页、触摸、返回按钮和蓝牙页面，**还没有编译过**，第一次编译如有报错，按报错修改。

> Windows 上位机在 `../host/`（`host/dist/SmartResistanceHost.exe`）。改了这里的指令或回复格式，要同步更新上位机，见 `host/README.md` 最后一节。

## 编译和烧录

1. VS Code 安装 PlatformIO IDE，打开本目录。
2. USB-C 接电脑。首次烧录：按住 BOOT（SW3）→ 点一下复位（SW2）→ 松开 BOOT。
3. 点 Upload。烧完按复位。

USB 口是复合设备：一个虚拟串口（指令和日志）加一个 HID（旋钮）。

## 屏幕、旋钮和触摸

- **旋钮**：转动 = 修改当前项，短按 = 下一项 / 执行，长按 0.6 秒 = 回主页
- **触摸**：点按钮、点数字；加减按钮按住会连续变化
- **左上角"< 返回"**：每个页面都有，点它回主页
- **语言**：设置页切换中文 / English（只影响屏幕，指令和回复始终是英文）

主页是 3 × 3 九宫格：

| 图块 | 功能 |
|---|---|
| 电阻 | 六位数字，点数字上半 +1、下半 -1；输出开关 |
| NTC | 点左右切换型号，-1 / -0.1 / +0.1 / +1 调温度，自动设置电阻 |
| 蓝牙 | 设备名、连接状态、打开/关闭、指令模式 / 串口透传 |
| 旋钮 | 选音量 / 滚轮 / 切歌 / 方向键，点开始后旋钮当 USB 键鼠用 |
| 串口 | J_DBG 串口数据；点波特率切换，暂停，清空 |
| 曲线 | TMP117 温度曲线；点间隔切换，清空 |
| 时钟 | 时间、板温、天气、IP |
| 继电器 | 单个继电器循环通断测试 |
| 设置 | 背光、屏幕翻转、中/英文、触摸校准、网络信息 |

**触摸校准**：第一次开机会自动进入校准，依次点四个角的十字。没接触摸屏时按一下旋钮跳过（以后不再提示）。
之后可以在设置页重新校准，或发指令 `TOUCHCAL`。屏幕翻转后不用重新校准。

**蓝牙两种模式**：

- 指令模式：手机发文本指令（和 USB 串口一样）
- 串口透传：手机收发的数据直接连到 J_DBG 的 TX/RX，相当于无线串口线；波特率在串口页设置

## 连接方式

所有通道使用同一套文本指令，一行一条，回复 `OK ...` 或 `ERR ...`。

| 通道 | 说明 |
|---|---|
| USB 串口 | 任意波特率 |
| 蓝牙 BLE | 设备名 `SmartR-XXXX`，Nordic UART 服务，手机用 nRF Connect / 串口类 App |
| Wi-Fi 网页 | `http://smartr.local` 或设备 IP |
| Wi-Fi TCP | 端口 5025 |
| HTTP 接口 | `GET /api/cmd?c=<指令>`、`GET /api/state` |
| 串口透传 | telnet 端口 23 ↔ J_DBG 的 TX/RX |

未配置 Wi-Fi 时设备自己开热点 `SmartR-XXXX`，密码 `12345678`，地址 `192.168.4.1`。用 `WIFI <ssid> <密码>` 配置路由器；连不上时 15 秒后自动回到热点。

## 分享到屏幕（图片 / txt，1.8.0 起）

主页"分享"（PAGE 20）。电脑或手机把图片、txt 文本发给板子，收到后自动打开：
- 电脑：上位机"分享到屏幕"页 → 选择图片 / 文本，或"发送剪贴板图片"（截图后直接发）；USB 串口最快，蓝牙 / 局域网也行。
- 手机：网页"分享到屏幕"卡片 → 选图片或 txt（Wi-Fi 打开的网页走 HTTP 上传，蓝牙网页走 FILEDAT 分块）。
- 发送端先转换：图片缩到 320×240 以内转成普通 JPEG（任何格式都行，EXIF 方向会摆正）；文本 UTF-8 / UTF-16 / GBK 都自动转成 UTF-8。
- 板子端：存进 3.4 MB 的 LittleFS 分区（`spiffs`，以前空着），断电不丢，保留最近 30 个；空间不够时自动删最旧的。
- 查看：列表里旋钮选、按下打开，按旋钮回列表。列表"删除"按两次删掉选中的文件。
  - 图片（1.9.0 可缩放）：全屏，转旋钮 = 缩放 1× / 2× / 4×，放大后点哪里就看哪里；点一下出工具条
    [返回][◀ 上一张][−][倍数（点它回 1×）][+][下一张 ▶]，4 秒后自动隐藏。
    发送端：USB / 局域网 / Wi-Fi 网页发 1280×960（4 倍放大仍有细节），蓝牙发 640×480（蓝牙慢）；
    板子按缩放把 JPEG 解码进 PSRAM 缓存（最大 1280×960×2 = 2.4 MB，离开分享页就释放），平移不用重新解码。
  - 文本：自动换行分页（GB2312 汉字 + ASCII，英文按单词换行，句末标点不放行首），旋钮或点上 / 下半屏翻页；
    底部 A− / A+ 调字号 16 / 24 / 32 / 48 px（16、24 是原生字库 `data/font_text16.bin` / `font_text24.bin`，32、48 是放大 2 倍），
    换字号保持当前阅读位置，字号记在 NVS。
- 指令：`FILENEW <IMG|TXT> <字节> <名字>` → `FILEDAT <偏移> <base64>`（每行 ≤120 字节，无回复，只收下一个偏移）→
  `FILEPOS?`（断点）→ `FILEEND <crc32>` → `OK ID=<n>`；`FILES?` 列表，`FILEOPEN <id>`，`FILEDEL <id|ALL>`；
  Wi-Fi：`POST /api/upload?kind=IMG|TXT&size=<字节>&name=<名字>`（multipart 文件字段）。

## 色环方块（小游戏，1.6.0 起）

主页"方块"（PAGE 18）。下落方块消行玩法，方块按电阻色环配色（棕 红 橙 黄 绿 蓝 紫），得分以 Ω 计
（消 1/2/3/4 行 = 100/330/680/1.5k Ω × 等级，E6 系列值；一落到底每格 +1 Ω）。每消 10 行升一级、下落更快，最高 15 级。
偶尔会落下银色的单格"熔丝"：落地时烧掉它所在的一整行，不管满没满（+47 Ω × 等级）。最高分存 NVS。

- 旋钮：转 = 左右移动，按一下 = 旋转，按住再转 = 一落到底，长按 = 回主页（游戏自动暂停，回来接着玩）
- 触屏：左侧 ◀ ▶（按住连续移动），右侧 暂停 / 旋转 / 落下，点方块区域也是旋转
- 游戏中新消息不弹横幅（状态栏显示"新消息 N"）
- 指令：`GAME?` 查状态；`GAME NEW|LEFT|RIGHT|ROT|DROP|PAUSE|RESUME` 远程操作（测试 / 截屏用）

## 手机（1.5.0 起）

- **蓝牙键盘 / 手机遥控**：板子同时是一个蓝牙键盘（BLE HID，"Just Works" 配对不用 PIN，最多 3 台）。
  iPhone：设置 → 蓝牙 → 其他设备里点 SmartR-XXXX。之后首页"遥控"页：旋钮 = 音量，按下 = 播放/暂停，
  按钮 上一首 / 下一首 / 拍照（音量+，相机快门）/ 上翻 / 下翻 / 静音 / 主页 / 清除配对。
  电脑也可以这样配对：板子没插电脑 USB 时，快捷键页和 USB 旋钮页改经蓝牙键盘发送。
- **iPhone 通知上屏**（ANCS）：配对后板子自动订阅 iPhone 通知，新通知（应用 · 标题 + 内容）做成卡片，和电脑转发的一样弹横幅、进"消息"页。
  iPhone 上该设备的设置里要打开"共享系统通知"。字库 `data/font_text16.bin` 由 `tools/make_textfont.py` 用 Noto Sans SC（OFL）生成：GB2312 全部汉字，16 px 2 位灰度。
- **不开电脑也能用的桌面功能**（1.7.0）：
  - **正在播放**：iPhone 的 AMS（苹果媒体服务），同一条蓝牙连接自动订阅，任何在 iPhone 控制中心显示的播放（Apple Music、QQ 音乐、网易云……）
    都会出现在"桌面"页卡片上（歌名 / 歌手 · 应用，板子用通知字库自己画）；卡片显示手机的歌时，上一首 / 播放 / 下一首和旋钮音量直接控制手机。
  - **时钟**：每次 iPhone 连上时读它的 CTS（当前时间服务）对时，带时区；连上有网的 Wi-Fi（比如手机热点）时还有 NTP。时区会保存（NVS），
    NTP 也用它（以前固定 UTC+8）。
  - **天气**：手机网页"时间与天气"卡片：输入城市或用手机定位 → 手机联网取 open-meteo 天气 → `WX` + `WXLOC` 发给板子；
    网页连上时自动同步时间、每 30 分钟刷新天气。`WXLOC` 把位置存进板子，之后板子只要连着有网的 Wi-Fi 就自己取天气（15 分钟一次），
    城市那一行也由板子自己画。电脑上位机"桌面助手"填了城市也会把位置发给板子。
  - `IPHONE?` 查 AMS / CTS 状态；`WXLOC?` 查保存的位置，`WXLOC OFF` 清除。
- **手机网页**：`docs/index.html`，同一个页面两种用法：
  - Wi-Fi：手机连板子热点（或同一个 Wi-Fi），浏览器开 `http://192.168.4.1` / 板子 IP，由板子自己提供（编译时 `tools/embed_web.py` 压缩嵌入）；
  - 蓝牙：https://jd7b94ftn2-alt.github.io/smartresistance/ （GitHub Pages，`docs/` 目录）。安卓 / 电脑 Chrome 直接用，iPhone 要用 Bluefy 浏览器（Safari 不支持网页蓝牙）。

## 充电宝（USB 主机，1.4.0 起）

板子的 USB-C 口可以当主机，直接读 onecell 充电宝（CH9347X 透传版固件）的电池数据，显示在"充电宝"页。

1. 充电宝页点"切到充电宝模式（重启）"并再按一次确认，或发 `USBMODE PBANK`。板子重启后 USB 口不再连电脑。
2. 充电宝**三击**按键进入"保留 PD"通信模式（充电宝继续给 C 口供电）。四击"强制受电"不能用：本板只能受电。
3. C 对 C 线把充电宝接到本板 USB 口，板子由充电宝供电，约 3 秒后显示电量、电压、电流、功率、温度、健康度、循环次数。

- 链路：CH9347X 枚举为 USB MIDI（1A86:E208）或 HID（1A86:FE30），里面是 Nvtmonitor 的 TLV 协议；
  每 0.5 秒查实时数据（0x80/0x03），每 30 秒查设备信息（0x80/0x04），只读，不需要认证密钥。
- 充电宝模式下没有 USB 串口和 USB HID（快捷键、旋钮键鼠、媒体键停用），上位机改用蓝牙或 Wi-Fi；看链路日志用 `PBLOG?`。
- 回电脑模式：充电宝页"切回电脑模式"，或 `USBMODE PC`。板子没有 BOOT 键，所以还有两条保底：
  充电宝模式下崩溃重启（panic / 看门狗）自动回到电脑模式；开机时按住旋钮也会强制回到电脑模式。
- 烧录前先回到电脑模式（1200 波特率复位只在电脑模式下有）。

## 互联网远程控制（MQTT）

板子主动连到一个 MQTT 服务器，电脑或手机也连到同一个服务器，就能在任何地方控制它，不需要公网 IP 或路由器端口映射。

1. 注册一个 MQTT 云服务（例如 EMQX Cloud Serverless），建好部署，添加一个用户名和密码。记下两个地址：
   设备用的 **TLS 地址和端口（一般 8883）**、网页用的 **WebSocket 地址（一般 `wss://…:8084/mqtt`）**。
2. 板子先连上能上网的 Wi-Fi（`WIFI <名称> <密码>`），再发：
   ```
   MQTT xxxx.emqxsl.cn 8883 用户名 密码
   ```
   回复里的 `TOPIC=smartr/xxxxxxxxxxxx` 就是这块板的主题，记下来。`MQTT?` 查看连接状态，`MQTT OFF` 关闭。
3. 电脑浏览器打开 `tools/remote.html`，填 WebSocket 地址、用户名、密码、设备主题，点连接。

| 主题 | 方向 | 内容 |
|---|---|---|
| `<主题>/cmd` | 发给板子 | 指令，一行一条，和 USB 串口完全相同 |
| `<主题>/reply` | 板子发出 | 每条指令的回复 |
| `<主题>/state` | 板子发出 | 状态 JSON（保留消息），变化时立即更新，至少 30 秒一次 |
| `<主题>/online` | 板子发出 | `1` 在线，`0` 离线（断线由服务器自动发出） |

也可以用 MQTTX 这类通用客户端或手机 MQTT App，按上表收发。

注意：

- 端口 1883 是不加密的明文连接，只建议在测试时使用；8883 走 TLS 加密。
- 板子没有存服务器的证书，TLS 只加密、不校验服务器身份。
- 拿到服务器账号的人就能控制板子，密码不要外传。
- 局域网里的网页（端口 80）和 TCP 5025 仍然**没有密码**。

## 字库

里出现的字自动生成（微软雅黑，只含用到的字）。**改了界面里的中文后要重新运行一次**：

```
python tools/make_fonts.py
```

## 电阻校准

40、400、4k 等档位实际焊的是 40.2、402、4.02k 等近似值。把每个权重的实测值用 `CAL W` 写入后，固件会用每个十进制位 0–15 的冗余组合，自动挑选最接近目标的继电器组合。未写入校准时按标称值工作。

## 安全行为

- 上电时所有继电器释放、输出断开，必须明确打开输出。
- 切换阻值时先断开输出，等网络稳定后再接通。
- 输出限制：5 V / 50 mA，不能当负载用。
